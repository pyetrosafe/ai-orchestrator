# AI Orchestrator

## English

AI Orchestrator is a project that combines a Cloud agent with Ollama running locally. The Cloud agent plans the work, breaks it into small tasks, delegates execution one task at a time, and validates the results. This keeps GPU usage sequential, organized, and easier to troubleshoot.

## Português

O AI Orchestrator é um projeto que combina um agente Cloud com Ollama executando localmente. O agente Cloud planeja o trabalho, divide-o em pequenas tarefas, delega a execução uma tarefa por vez e valida os resultados. Isso mantém o uso da GPU sequencial, organizado e mais fácil de diagnosticar.
